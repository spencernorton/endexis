# Support

There is no support contract and no e-mail address. Use these four routes:

- **Usage questions and configuration:** open a thread in [GitHub Discussions](https://github.com/spencernorton/endexis/discussions).
- **Reproducible bug reports:** open an issue using the bug report form in [GitHub Issues](https://github.com/spencernorton/endexis/issues).
- **Feature requests:** open a proposal in [GitHub Issues](https://github.com/spencernorton/endexis/issues).
- **Security vulnerabilities:** use [private vulnerability reporting](https://github.com/spencernorton/endexis/security/advisories/new) per [SECURITY.md](SECURITY.md).
